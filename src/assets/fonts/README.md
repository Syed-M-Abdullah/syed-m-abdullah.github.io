# Fonts

Self-hosted WOFF2 variable fonts, Latin subset (copied from the `@fontsource-variable` packages):

- `plus-jakarta-sans-latin-wght-normal.woff2` — Plus Jakarta Sans, © Tokotype, SIL Open Font License 1.1
- `inter-latin-wght-normal.woff2` — Inter, © The Inter Project Authors, SIL Open Font License 1.1

License text: https://openfontlicense.org/open-font-license-official-text/

They are declared with `@font-face` at the top of `src/styles.css`; the headline font is preloaded
in `src/routes/__root.tsx`.
